Administração do banco · alunos

Turma

Um nome por vaga, quantas vagas forem preciso. Ao salvar, cada vaga com nome ganha usuário e schema próprios, se ainda não tiver, entra na lista do Executor de SQL e recebe a tabela aluno vazia; apagar o nome tira o acesso, mas o schema e as tabelas daquela vaga ficam. Cada vaga é um schema: trocar o nome de vaga leva o novo aluno para as tabelas que já estão nela.

Executar script em todos os alunos

O script roda uma vez em cada schema, com o schema como padrão: escreva CREATE TABLE curso (...), sem prefixo. Cada schema roda separado, e o erro num deles não desfaz os outros. Tabelas criadas pelo script ficam com o dono do schema. Se o script terminar num SELECT, as linhas aparecem. Para rodar num só, escolha o cartão dele lá em cima ou comece com SET search_path TO aluno01;.

Quantidade de duplas

De 1 a 12, para o projeto Java da Aula 10. As duplas acima da quantidade ficam sem acesso ao banco. Uma dupla nova já recebe a tabela aluno vazia.
